# aa くコ:彡

This repo hosts a collection of Japanese *Shift_JIS* ascii art (also referred to as "aa") that I extracted from [http://en.utf8art.com](http://en.utf8art.com) in early 2024. It's a large collection of ~55k artwork originally appearing on the [2ch.net](https://2ch.net) textboard that have been tagged and categorized in English.

This repo is organized as a directory of simple HTML files that can be served by Apache's auto directory listing (`mod_autoindex` & `mod_include`). The fonts are from [AAHub](https://fonts.aahub.org/).

You can view it live at [https://aa.mozz.us](https://aa.mozz.us).
